# JavaScript Modules Mini Lab

This project reorganizes two previous assignments using JavaScript import and export statements.

## Projects Used

- OOP Lab
- Movie Watchlist

## OOP Lab Modules

- The character files export the Character, Companion, Adventurer, and Enemy classes.
- AdventurerFactory.js exports the adventurer factory.
- duel.js exports the duel function.
- oop.js imports and uses the modules.

## Movie Watchlist Modules

- movieData.js exports the starter movies.
- validation.js exports the validation functions.
- movieDisplay.js exports the display functions.
- movieActions.js exports the movie button and filter functions.
- script.js imports and uses the modules.

## How to Run

Run the OOP Lab:

```bash
cd oop-lab
node oop.js
```

Open movie-watchlist/index.html with Live Server to run the Movie Watchlist.

## What I Learned

I learned how to export code from one file and import it into another file. This makes the projects easier to organize and reuse.
